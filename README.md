# How to export ChatGPT to Word

ChatGPT answers are easy to copy, but pasting into Word often breaks headings, tables, and code. [ChatGPT2Word](https://chatgpt2word.com) converts ChatGPT / Markdown in the browser into an editable `.docx`.

- Free: 2 exports a day, no account
- Pro: $4.99 one-time

## Common exports

| Need | Tool |
| --- | --- |
| Full conversation | [Export ChatGPT conversation to Word](https://chatgpt2word.com/export-chatgpt-conversation-to-word) |
| Markdown notes | [Markdown to Word](https://chatgpt2word.com/markdown-to-word) |
| Tables from ChatGPT | [ChatGPT table to Word](https://chatgpt2word.com/chatgpt-table-to-word) |
| LaTeX formulas | [LaTeX to Word](https://chatgpt2word.com/latex-to-word) |
| Code blocks | [ChatGPT code to Word](https://chatgpt2word.com/chatgpt-code-to-word) |
| Mermaid diagrams | [Mermaid to Word](https://chatgpt2word.com/mermaid-to-word) |
| Claude chats | [Claude to Word](https://chatgpt2word.com/claude-to-word) |

## Quick steps

1. Copy the ChatGPT reply (or Markdown) from the chat.
2. Paste into the matching tool above.
3. Download the `.docx` and open it in Word or Google Docs.

More detail: [How to export ChatGPT to Word](https://chatgpt2word.com/how-to-export-chatgpt-to-word).
